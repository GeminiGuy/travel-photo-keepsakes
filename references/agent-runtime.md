# 跨 Agent 运行环境

本技能是图像设计与执行指引，不自带模型服务。开始出图前识别当前环境已有的看图、参考图生图/编辑、保存文件与查看结果的能力。

## Codex 内置生图路径

内置 `image_gen` 可用时优先采用，遵循当前工具 schema 及 imagegen 技能（若存在）。本地图片先查看；支持 `referenced_image_paths` 的环境传入真实路径，无路径的会话图片按工具规范选择近期图片。不要把参数当成所有 Agent 通用接口。每个独立成品分别调用，重复生成时始终明确原照角色。

## OpenClaw、Claude Code 及其他 Agent

使用用户已配置且授权的参考图生图工具/MCP/provider。先读取其说明，映射原始照片、提示词、方向、目标比例和返回文件，不凭空编造工具名或参数。不要求工具必须叫 `image_gen`，也不要求存在 Codex 特有的 `view_image`；使用当前环境等效能力。

有多个可用工具时，优先用户指定的工具，再选支持参考图且能保存结果的工具。不能因缺少内置工具而暗中开通付费服务、更换账号、安装插件或索取聊天中的明文密钥。新增服务按用户授权和环境权限处理。

## 能力不足

只有看图/文本能力时，可以分析照片并准备各张的最终提示词，明确说明图片尚未生成，以及需要「支持参考图片的图像生成工具」。不使用 ASCII、SVG 或照片加滤镜冒充珐琅/插画生图结果。不声称原照像素无损或已验证实际文件尺寸，除非有证据。

输出工具仅返回远程链接时，按该环境的媒体保存权限交付；不能伪造本地路径。
